1.5.1 - Nov 13th 2026
=====================

Minor release with bug fixes and performance improvements:

Pipeline:

* Job dispatch: Add option to stream from remote zarr files in aind mode (job-dispatch PR#40)
* Skip spike sorting and postprocessing for "failed" preprocessing steps (too short/too many bad channels) (#151)
* Add saturation detection and removal in preprocessing, and reuse pre-compute ones in QC
* Per-stream channels joined on recording name: each stream's postprocessing, curation and visualization start as soon as its own upstream steps finish (#152)
* Run quality control per stream right after visualization, instead of after the results collector (#152)
* Fix NWB ecephys chunking/margins for performance (nwb-ecephys PR#31)
* Write sparse waveform_mean/sd in NWB units (nwb-units PR#37)

Environment:

* Bump up Dartsort to version 0.5.32
* Rebuild Dartsort image off base spikeinterface image (spikeinterface/dartsort-base:0.5.32_cuda-12.9.1)
* Bump up s3fs to 2025.7.0

CI:

* Add workflow with remote zarr streaming test

Parameters

* Added ``min_recording_duration`` parameter to skip recordings shorter than the specified duration (-1 disables this check) (#153)
* Added ``job_dispatch.nwb_files`` to the parameters schema. The job dispatch step reads it, but the schema rejected it, so ``--job_dispatch_args "--nwb-files ..."`` failed validation from 1.5.0
* Remove ``preprocessing.motion.extimate_kwargs.win_step_norm/win_scale_norm``
* Add ``--aind_opto`` CLI parameter to enable AIND-specific opto preprocessing

* ``neo`` version: 0.14.6
