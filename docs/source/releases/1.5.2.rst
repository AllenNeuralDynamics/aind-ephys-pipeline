1.5.2 - WIP
===========

Minor release with performance improvements:

Pipeline:

* Add ``global_job_kwargs`` parameter to configure default job arguments for all steps
  (``chunk_duration="1s"``, ``progress_bar=false``, ``mp_context="forkserver"``). Per-step ``job_kwargs`` now
  default to ``{}`` and override the global values key by key (see :ref:`global-job-kwargs`).
* Quality control, NWB ecephys and preprocessing now use ``forkserver`` instead of ``spawn`` by default.
* Params files without ``global_job_kwargs`` (from earlier releases) still work: the pipeline fills it in from
  ``default_params.json`` and prints a warning. Their per-step ``job_kwargs`` keep applying on top.
* Fix ``dartsort`` external motion
* Add warning when extra params are present in the params file

Steps:

* All steps that use job kwargs (preprocessing, preprocessing-opto, spike sorters, postprocessing, curation,
  visualization, processing-qc, ecephys-nwb) read ``global_job_kwargs`` merged with their own ``job_kwargs``.
